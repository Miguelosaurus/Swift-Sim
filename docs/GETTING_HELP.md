# Get help from your agent

Your agent can usually read build and delivery logs on your Mac. You do not
need to copy every error into your chat.

If the agent needs details from the iPhone, open **Details** on the error and
tap **Copy details**. Paste the report into your existing chat. It includes the
screen, problem, and available app, build, or request IDs. The button changes
to **Copied** when it is ready to paste.

Build logs and the Simulator console also have **Copy details**. This is an
optional troubleshooting action; copying is never needed to retry or recover.

Copying stays on your clipboard. Swift Sim does not upload the report or send
it to an agent automatically. Reports remove links, recognized credentials and
private key material, and shorten home-directory paths. Review logs before
sharing them: app logs can contain information Swift Sim cannot identify.

A missing confirmation does not mean an action failed. Ask your agent to check
the current build, install, or testing request before repeating it. If stopping
a test cannot be confirmed, use **Stop Server** in the testing app's notification.
