## Engine handoff finding

The prior engine accepted SIGTERM but remained alive and retained its live
listener. The replacement control socket initially belonged to a new engine
that could not bind the occupied port. The original stop code waited only
300 ms and then discarded tracking without confirming process exit.

The obsolete process was stopped only after independently rechecking its
exact start time, user, executable and listener ownership. The private audit
is `.build/callback-v3-bootstrap/old-engine-stop-audit.json`. The corrected
normal stop path now waits for confirmed exit and fails closed on timeout or
ownership refusal, preserving installation and records without force-killing.
Tests exercise graceful exit, a real SIGTERM-ignoring child and refusal.

The running engine subsequently restored 861 captured compiler entries from
its existing private snapshot. A separate attempt to register from the old
result bundle failed safely because normal artifact retention had pruned that
bundle. No result bundle or compiler provenance was fabricated, and no
additional app build was started. Ordinary phone disconnection still means
waiting for the matching app, rather than missing compiler setup.
